### 1.1. Сортировка пузырьком (Bubble Sort)

В данном алгоритме на каждом шаге находится наибольший элемент из двух соседних и переставляется в конец пары. Из принципа работы алгоритма (при каждом прогоне цикла большие элементы "всплывают" к концу массива).

- Лучший случай: **O(n)** — входной массив уже упорядочен.
- Средний случай: **O(n²)**.
- Худший случай: **O(n²)** — массив упорядочен в обратном порядке.
- Дополнительная память: **O(1)** для самого алгоритма сортировки (не учитывая копирование массива в реализации).
- Стабильность: **стабильный** алгоритм.

Принцип работы алгоритма:

1. Берется первый элемент массива и сравнивается со вторым. Если первый больше второго - они меняются местами, в обратном случае ничего не происходит.
2. Берется следующий элемент массива и п.1 повторяется. 
3. В конце сравнивается предпоследний и последний элемент, как в п.1. Так находится самое большое число в массиве.
4. Цикл возвращается в начало и начинает сравнение со второго элемента и тд. пока цикл не дойдет до последнего элемента. Конечный проход сравнивает все элементы, и если в результате его работы не было произведено перестановок, значит массив отсортирован.

```python
def bubble_sort(a: list) -> tuple[list, int, int]:
    
    copy_a = a.copy()
    n = len(copy_a)
    swapps = 0
    count = 0
    if n > 0:
        for i in range(n - 1):
            swapped = False

            for j in range (n - 1 - i):
                count += 1
                if copy_a[j] > copy_a[j + 1]:
                    copy_a[j], copy_a[j + 1] = copy_a[j + 1], copy_a[j]
                    swapped = True
                    swapps += 1
            if swapped == False:
                break
    return (copy_a, count, swapps)
```
### 1.2. Сортировка вставками (Insertion Sort)

В данном алгоритме на каждом шаге берется один из элементов массива, находится позиция для вставки и вставляется на свое место. 

- Лучший случай: **O(n)** — массив уже упорядочен.
- Средний случай: **O(n²)**.
- Худший случай: **O(n²)** — обратный порядок.
- Дополнительная память: **O(1)** для сортировки (не учитывая копирование массива).
- Стабильность: **стабильный** алгоритм.

Принцип работы алгоритма:

1. Алгоритм условно делится на две части: отсортированную и неотсортированную. Первый элемент изначально считается отсортированным.
2. На каждом шаге алгоритм берет первый элемент из неотсортированной части и сравнивает его с другими элементами справа налево. Все элементы, которые больше выбранного, сдвигаются вправо, после чего выбранный элемент вставляется в освободившееся место.
3. Процесс продолжается до тех пор, пока весь массив не будет отсортирован.

```python
def insertion_sort(a: list) -> tuple[list, int, int]:

    copy_a = a.copy()
    n = len(copy_a)
    count, swapps = 0, 0
    if n > 0:
        for i in range(1, n):
            for j in range(i, 0, -1):
                count += 1
                if copy_a[j] < copy_a[j - 1]:
                    copy_a[j], copy_a[j - 1] = copy_a[j - 1], copy_a[j]
                    swapps += 1
                else:
                    break
    return copy_a, count, swapps
```
### 1.3. Сортировка выбором (Selection Sort)

Сортировка выбором делит массив на две части: отсортированную и неотсортированную. На каждом проходе алгоритм находит минимальный элемент в неотсортированной части и ставит его в конец отсортированной.

- Лучший, средний и худший случаи: **O(n²)**.
- Количество сравнений не зависит от исходного порядка элементов и равно `n(n − 1) / 2`.
- Количество обменов не превышает `n − 1`.
- Дополнительная память: **O(1)** для сортировки (не учитывая копирование массива).
- Стабильность: **нестабильный** (при перестановке равные элементы могут поменяться местами)

Принцип работы алгоритма:

При каждом проходе выбирается минимальный элемент и смещается в начало. При этом, Каждый новый проход начинается со следующего элемента (первый проход - первый элемент, второй - второй элемент и тд.)

```python
def selection_sort(a: list) -> tuple[list, int, int]:

    n = len(a)
    copy_a = a.copy()
    count, swapps = 0, 0
    if n > 0:
        for i in range(0, n - 1):
            m = copy_a[i]
            index = i
            for j in range (i + 1, n):
                count += 1
                if m > copy_a[j]:
                    m = copy_a[j]
                    index = j

            if index != i:
                swapps += 1
                temp = copy_a[i]
                copy_a[i] = copy_a[index]
                copy_a[index] = temp
    return copy_a, count, swapps
```
### 1.4. Рандомизированная быстрая сортировка (QuickSort)

Для каждого подмассива случайным образом выбирается опорный элемент (pivot). Остальные элементы распределяются на три группы: меньше опорного, равные ему и больше него. Затем рекурсивно сортируются группы меньших и больших элементов.

Использование трёх групп позволяет корректно и эффективно обрабатывать повторяющиеся значения. Для подмассивов длиной 0 или 1 рекурсия завершается.

- Ожидаемая временная сложность: **O(n log n)**.
- Худший случай: **O(n²)**.
- Дополнительная память: в данной реализации используются дополнительные списки и рекурсивные вызовы, поэтому она не является реализацией QuickSort с разделением массива на месте.
- Стабильность: **стабильный** в данной конкретной реализации, поскольку элементы добавляются в группы в исходном порядке.

Принцип работы алгоритма:
 
1. На очередном шаге выбирается опорный элемент (pivot). Он может выбираться по определенному условию или генерироваться случайно.
2. Все остальные элементы массива сравниваются с опорным и те, которые меньше него, ставятся слева, а которые больше или равны - справа от опорного элемента.
3. Для двух получившихся блоков массива (меньше и больше опорного) производится такая же операция - выделяется опорный элемент и повторяются действия из п.2

```python
def quick_sort(a: list, rng: random.Random | None = None) -> list:
    if len(a) <= 1 : return a

    copy_a = a.copy()

    if rng is None:
        rng = random.Random()

    pivot = copy_a[rng.randrange(0, len(copy_a))]

    left = []
    right = []
    eq = []

    for i in copy_a:
        if i < pivot:
            left.append(i)
        if i > pivot:
            right.append(i)
        if i == pivot:
            eq.append(i)

    copy_a = quick_sort(left, rng) + eq + quick_sort(right, rng)
    return copy_a
```
